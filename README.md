# Sentiment Analysis Project

This project builds a sentiment analysis workflow using a notebook and a text dataset.

## Files
- SentimentAnalysis.ipynb: Jupyter notebook containing the full analysis pipeline.
- TextAnalytics.txt: Dataset used for sentiment analysis.

## What this project does
- Loads and preprocesses text data
- Performs sentiment analysis
- Trains and evaluates machine learning models
- Demonstrates a simple Flask API for prediction

## How to run
1. Open SentimentAnalysis.ipynb in Jupyter Notebook or VS Code.
2. Run the cells in order.
3. Make sure the dataset file TextAnalytics.txt is in the same folder.

## Requirements
Install the required Python packages used in the notebook, such as:
- pandas
- numpy
- nltk
- scikit-learn
- matplotlib
- wordcloud
- contractions
- flask
